# Архив одноразовых миграций

Скрипты в этой папке использовались для исторических преобразований исходников. Результат уже находится в `app/`, `remote/` и `core/`.

Они не входят в текущий GitHub Actions workflow и не должны запускаться повторно: повторное применение может перезаписать актуальный код или вернуть устаревший протокол.

Для новых изменений редактировать исходные файлы напрямую, добавлять тесты и обновлять `PROJECT_STATUS.md`/`CHANGELOG.md`.
